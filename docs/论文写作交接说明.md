### 红线 B：措辞分级——因果与相关不能混

| 可以这样写 | 证据 |
|---|---|
| ✅ **写入的坐标分配是因果必要的** | A/B 级：能量严格匹配的 shuffle 对照，n=12，t=+5.94；两次独立系列 t=+4.86 / +5.45；3 倍写入强度内稳健 |
| ⚠️ **只能说"相关"**：落点 = 与新任务梯度的内积对齐 | C 级：`cos(g₀, ΔW_fast)`→`gain@40` r=+0.87（perm p≈0.000，FDR q≈0.003，LOO [0.81,0.91]，控范数后 partial≈0.77）——**没有方向操纵实验** |
| ❌ 不能写：参数级 / 子空间级选择性 | 论文已明确声明**没有**；`success` 是全局标量 |
| ❌ 不能写：经验越多学得越快 | 已证伪（p=0.17 / 0.82，d=−0.17） |
| ❌ 不能写：Q 通路实现了选择性巩固 | 数值+因果双重惰性（‖Q‖≈0.002，仅占写入能量 0.4%；`qonly≈nocons`） |

> 想把"对齐"从相关升格为因果，需要**方向性干预**（例如把 `W_fast` 投影到与 `g₀` 正交的子空间后再写入）。在此之前，句子的主语必须落在**坐标分配**上。

### 红线 C：定位——不对标 SOTA

本文**不是**提出高性能持续学习算法，而是**上下文校准实验（context-calibration）**，用于剖析一种涌现式可塑性机制。性能只作为"现象存在"的佐证。

- 不要写"DLA 优于/低于 EWC、replay 等 SOTA"这类整体性判断。
- 可以正面写：在**修复后**的同协议对比里（`results/cloud/dla_cl/gpt2/`，n=10），DLA 落在 stability–plasticity **前沿内部**，而非落后一个身位；但贡献不在这里。
- ⚠️ 该表（10 任务 CL 基准）与主线的 EH/HE `LE_D` 协议**不是同一协议**，不可混列。

## 5. 术语与符号

| 符号 | 含义 |
|---|---|
| `W_slow` | 长期知识（慢权重） |
| `W_fast` | 对（Adam 整形后）梯度的**带遗忘积分**，≈1 个 stage 的记忆窗 |
| `P` | 逐参数可塑性（softplus 正缩放，只调幅度不改符号） |
| `Q` | 睡眠资格迹 `EMA(dw·success)`，**success 为全局标量** |
| `W_eff` | `W_slow + softplus(P)·W_fast` |
| 睡眠（任务边界） | `W_slow += β·Q + γ·W_fast`；`W_fast *= decay`；`Q *= 0.7`；reset moments |
| `γ_scale` | `audit_b3.py --gamma` 的**缩放系数**，乘在**可学习的** `consolidate_fast_direct`（config 默认 0.15，经 sigmoid）上。**γ_scale=1.0 是项目默认，不是系数等于 1.0** |
| `LE_D` | 在未见域 D 上的学习效率指标 |
| `gain@40` | 第 40 步相对起点的困惑度增益（主线指标） |
| `retention` | `mean(after/end)`，越高越好 |
| EH / HE | easy→hard / hard→easy 两种历史顺序；**效应在 HE 臂**，EH 臂平坦 |
| unified batch | 论文数字的**权威聚合口径**（`audit_batch2_retention_alloc.md`） |
| harness parity | Mac 侧与存档服务器运行的等价性（mean \|Δppl\| ≈ 0.24） |

## 8. 口径约束（写作时最容易踩的三个坑）

1. **协议不能混**：EH/HE 的 `LE_D` 协议 ≠ 10 任务 CL 基准 ≠ 124M 的 P1 分配实验。三者的数字不可放进同一张表。
2. **n 不能含糊**：主线 n=12（配对）；`qonly` n=4；γ 扫描各 n=12；δ 轴 n=6（**指示性，不构成结果**）；基线 n=3/5（且已作废）。
3. **数字必须能落到文件**：凡在正文出现的数，都应能在 §3 的归档文件里复算。复算不出来的数不要写——这是本项目自己的审计规则。
