## 一、一句话主张

> **系统里没有任何显式选择目标，但睡眠期的标量写回产生了功能性的选择性效应；
> 这个效应的全部效力取决于"写落在哪些坐标上"，而落点由 `W_fast` 自身的梯度历史结构
> 自发决定。**

对照实验直接支撑这句话：把写入的总能量、规则、系数全部保持不变，**只打乱坐标分配**，
效应即被完全消除（`direct − shufwrite`，n=12，配对 t=+5.94，11/12 胜）。

## 二、理论叙事：为什么"没有选择目标"却出现了选择性

### 2.1 泄漏积分 = 对历史梯度的低通滤波

`W_fast` 不是存储内容，而是**对（经 Adam 整形后的）梯度做带遗忘的积分**：

```
W_fast ← decay · W_fast + η · dw          # 每个 stage 的连续累积，睡眠时乘 decay
```

带遗忘的积分在信号意义上就是**一阶低通滤波**：高频（噪声、单步抖动）被衰减，
低频（跨步持续出现的、结构化的方向）被保留。于是 `W_fast` 保存的是
**近期任务的结构化梯度方向**，而不是近期梯度的平均快照。

### 2.2 任务间的底层梯度方向天然相似 → 坐标对齐

神经网络在**关联性较强**的不同任务上，底层特征更新的梯度方向天然具备相似性。
`W_fast` 保存的近期结构，会与后续新任务的梯度向量自然形成**内积对齐**，
即**坐标对齐**现象。

### 2.3 该对齐是涌现行为

代码里没有任何"对齐"逻辑：没有对齐损失、没有选择器、没有重要性打分。
`success` 门控（唯一显式设计的"选择"）是**全局标量**，只做 step 级门控，
无 parameter/subspace 级选择——而它在数值与因果上都是惰性的（见 3.6）。
对齐完全是**泄漏积分机制 × 数据自身梯度结构**相互作用的结果。

### 2.4 睡眠期的标量写回

睡眠（任务边界）用**标量系数**把 `W_fast` 写进 `W_slow`：

```
W_slow += β·Q + γ·W_fast        # Q 通路（success 门控，惰性）+ DIRECT 通路（标量，有效）
W_fast *= 0.5 ; Q *= 0.7 ; reset m/v
```

规则本身不含任何坐标级选择，但**这套自发完成的坐标对齐写入**带来了功能性的选择性效应：
一方面给新任务的前向适应提供增益，另一方面依托睡眠边界机制保留原有记忆，
不引发严重的灾难性遗忘。

### 2.5 对照实验：必要条件的证据

能量守恒前提下打乱权重坐标（`shufwrite`），对齐关系被破坏，选择性增益随之消失。
这是论文中心声明的**因果**证据。

> ⚠️ **措辞边界（务必分级，别混为一谈）**
> - 已证实（A/B 级）：**写入的坐标分配是因果必要的**。证据：能量严格匹配的 shuffle 对照，
>   两次独立系列一致（t=+4.86 与 +5.45），且在 3 倍写入强度范围内稳健。
> - 仅有相关（C 级）：**"落点 = 与新任务梯度的内积对齐"这一具体机制**。证据是
>   per-seed `cos(g₀, ΔW_fast)` 与 `gain@40` 的相关（r=+0.87，perm p≈0.000，FDR q≈0.003，
>   LOO [+0.81,+0.91]，控制范数混淆后 partial r≈0.77）——**没有方向操纵实验**。
> - 因此 §2.5 写"证明对齐是必要条件的"时，主语应落在**坐标分配**上；
>   把"对齐"升格为机制主张需要新的干预实验（见 §六 待办）。
>
> 这条边界是本项目自己审出来的（`docs/mechanism_audit.md`：曾据此回撤过一次中心声明），
> 写作时不要退回旧表述。

## 三、实验证据地图

### 3.1 已证实：坐标分配因果必要（**B 级**，论文中心声明）

| 对比 | 指标 | 效应 | 统计 |
|---|---|---|---|
| `direct − shufwrite` | `final_ppl` | +1.0457 ± 0.6103 | t=+5.94，11/12，dz=+1.71 |
| 同上，独立系列 | 同上 | +0.0106（gain@40） | t=+4.86 |
| 同上，unified batch | 同上 | +0.0115（gain@40） | t=+5.45 |

- 能量严格匹配，所以排除了"能量差异"这一替代解释；`pre` 不平衡 +0.326（可忽略）。
- 归档：`results/mac_audit/dla_audit/{direct,shufwrite}/`；报告：`selectivity_test_n12.md`、
  `audit_batch2_retention_alloc.md`。

### 3.2 效应不依赖单一写入强度（**B 级**，"最强的一条"）

| γ_scale | direct | shufwrite | 配对 gap | t |
|---|---|---|---|---|
| 0.5 | +0.0059 | +0.0035 | +0.0024 | +1.82 (n.s.) |
| 1.0 | +0.0140 | +0.0025 | +0.0115 | **+5.45** |
| 1.5 | +0.0241 | +0.0040 | +0.0201 | **+4.78** |

相对 `nocons` 地板（+0.0027）：**打乱写入始终趴在地板上**（Δ=+0.0008 / −0.0002 / +0.0013，
全部 n.s.，|dz|≤0.30），而匹配写入随强度抬离地板（t=+2.38 / +7.36 / +6.58）。

> **给错配的写加能量纯属浪费。起作用的是"写在哪里"，不是"写了多少"。**

- 归档：`results/mac_audit/dla_audit/{g0.5,g1.5,g0.05,d0.25,d0.75}/`；报告：`a1_gamma_final.md`。

### 3.3 载体：历史效应存在于 `W_fast`（**A 级**）

交换注入实验（HE 学习者 ← EH 学习者的 `W_fast`），三个规模方向一致：

| backbone | n | Δfinal | t | 变差 |
|---|---|---|---|---|
| gpt2 | 12 | +0.7752 | +9.33 | 12/12 |
| gpt2-medium | 12 | +0.4421 | +4.14 | 10/12 |
| gpt2-large | 12 | +0.9054 | +5.91 | 12/12 |

排除起点假象（Δpre 仅 −0.006~−0.013，而 Δfinal 明确变差）；第二骨干（Shakespeare，n=9）
复现（t=−7.13）。
⚠️ **限定**：这证明 `W_fast` **因果地影响状态**；历史**特异性**另见 §六（仅 ~7%）。

### 3.4 边界（decay + moment reset）保护旧任务（**A 级**）

```
nosleep vs direct :  t = +10.26（不睡显著更差）
T10 十任务（n=8）:  最早任务 end ppl  direct 38.27 < nocons 39.03 < nosleep 39.51
                    direct vs nocons  t = −3.60
                    direct vs nosleep t = −10.27
```

**关键区分**：保护旧任务的是**边界本身**，不是写入——`nocons`（不写但保留边界）
已显著优于 `nosleep`。这条是 §4.3 拆分表述的直接依据。

### 3.5 直接写回是有效的 CL 原语（**A 级**，单一 backbone）

T10 十任务跨域：retention `direct` 最好，forward 不更慢（vs nosleep t=−3.93），
10 个任务上 forward 斜率全部持平/负——无塑性崩塌。

### 3.6 阴性结论（**D 级**，是论文张力的来源）

```
‖Q‖ ≈ 0.002  vs  ‖W_fast‖ ≈ 3.6    →  Q 写入仅占 0.4%
qonly ≈ nocons（n=4）               →  因果惰性
```

> **显式设计的选择机制（success-gated Q）不起作用；
> 起作用的是一个没有选择目标的标量写回。**

另一条阴性：**"经验越多 → 学得越快"（B 命题）不成立**——Stage 5–8 多协议阴性
（p=0.17 / 0.82，d=−0.17）。

### 3.7 相关级（**C 级**）

- 方向痕迹自组织且可预测适应：`cos(g₀, ΔW_fast) → gain@40`，r=+0.87（详见 §2.5 的边界说明）。
- 模块级收敛到 MLP/attention，与因果模块一致。
- **同时的阴性**：EH 臂无此效应；宏观几何不可分（norm/cosine 与同历史跨 seed 噪声同级）；
  PCA PC1≈20%——即**宏观几何不是载体**。

## 四、三条修订要点的落实状态

### 4.1 `topk_signed` 算子（已实现，扫描进行中）

**动机**：原 `topwrite` 把入选坐标的**幅值替换成常数**，丢弃正负符号，因此无法排除
"单纯能量集中"带来的假阳性——它既可能是"集中化没用"，也可能是"符号没了所以没用"，
两者无法区分（`docs/mechanism_audit.md` §3.2）。

**新算子**（`analysis/wfast_geom/audit_b3.py`，`--variant topk_signed --topk-frac f`）：

```
1) 按 |W_fast| 取 Top-k（k = f · N）
2) 完整保留入选坐标的正负符号
3) 能量归一缩放，使 ‖写入‖ 严格等于 direct 的写入能量 γ·‖W_fast‖
   → 与 direct 的唯一差别只剩"落在哪些坐标"
```

**已完成的验证**（对真实函数做的单元检查，非复制的逻辑）：

| 性质 | 结果 |
|---|---|
| 能量匹配（各 frac） | 相对误差 **0.00e+00**（机器精度） |
| 符号保留 | 全部入选坐标通过 |
| `frac=1.0` 退化 | 与 `direct` **逐元素精确相等**（实现自检） |

**扫描设计**（48 job：frac ∈ {1.0, 0.5, 0.2, 0.05} × seeds 0–11，HE 臂）：

| frac | 作用 |
|---|---|
| **1.0** | 自检：必须复现归档的 `direct` 臂，同时给出本批次的**harness 噪声地板** |
| **0.2** | 与 `topwrite` 的 20% 浓度**正面单挑**（有符号 vs 无符号） |
| 0.5 / 0.05 | 夹逼，使结论成为**剂量-反应**而非单点 |

**判定规则（在见到数据之前就固定，避免事后拟合命名）**：

- `topk_signed ≈ direct` → 命名 **稀疏对齐选择**（稀疏的、带符号的坐标子集已足够）
- `topk_signed ≈ shufwrite` → 命名 **分布式对齐选择**（只有完整的分布式模式有效）
- 介于两者 / 随 frac 变化 → **报告剂量-反应，不领任何命名**

驱动脚本：`analysis/wfast_geom/queue/{run_topk.sh,topkjob.sh}`；
分析脚本：`analysis/wfast_geom/summary_topk.py`（统计量与 `a1_final.py` 同一套，
配对 t / dz / 内联 t 表，保证与写入强度报告同口径）。

> **这条正好补上 `docs/proven_claims.md` §四"未证明"表里的一格**：
> "集中化/稀疏是不是解释 ❌ 从未检验（`topwrite` 丢符号，`topk_signed` 从未跑）"。

### 4.3 抗遗忘因果拆分（定稿版表述）

整体抗遗忘效果由**两层机制叠加**构成，两层都有独立证据：

**第一层：睡眠边界机制——提供基础水平的记忆保留、抗遗忘基底**

```
nocons（不写，但保留边界）vs nosleep（不保留边界）:  t = +10.26
T10（n=8）:  direct 38.27 < nocons 39.03 < nosleep 39.51
             direct vs nosleep  t = −10.27
```

边界本身（decay + moment reset）就带来了显著保留，与"写了什么"无关。

**第二层：坐标对齐式权重写入——在基底之上带来增量记忆留存 + 新任务前向适应增益**

```
direct vs nocons（增量留存）  : t = +5.30（gain@40，n=12）
shufwrite ≈ nocons            : nocons − shufwrite = −0.0006，t = −0.38（打乱写入 = 没有写入）
direct − shufwrite（中心声明）: t = +5.94（final_ppl，n=12）
```

增量来自**对齐的写入**，而非"写入本身"——打乱坐标后增量归零。

> **一句话**：边界负责"不遗忘的底"，对齐写入负责"在底之上的增量与增益"。
> 这条拆分的价值在于：它把"抗遗忘"从单一机制主张，变成两个**可分别消融**的机制，
> 而两者在实验上已被分别消融过（`nosleep` 消融第一层，`shufwrite`/`nocons` 消融第二层）。

## 五、论文骨架（建议章节）

1. **现象**：没有选择目标，却出现了功能性选择（§一 + §3.1）。
2. **机制**：泄漏积分 → 低通滤波 → 坐标对齐 → 睡眠标量写回（§二）。
3. **因果证据**：能量匹配 shuffle 对照 + 写入强度稳健性 + 载体定位（§3.1–3.3）。
4. **抗遗忘的两层拆分**：边界基底 + 对齐增量（§3.4 + §4.3）。
5. **张力**：系统里显式设计的"选择"（Q）是惰性的（§3.6）。
6. **定位与边界**：上下文校准实验，不对标 SOTA；逐条标注证据等级（§4.2 + §六）。
