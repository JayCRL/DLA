## 一、A/B 级：核心因果结论

### ⭐ 1. 写回的**坐标分配**是因果必要的（论文中心声明）

```
对照：shufwrite = 逐矩阵置换 γ·W_fast，总能量/规则/系数完全相同
      只有「哪些坐标收到写入」被破坏

指标：final_ppl（不含 pre，corr(pre,effect)=+0.158 ← 干净）
      direct − shufwrite = +1.0457 ± 0.6103
      t = +5.94   11/12 seeds    dz = +1.71
      pre 不平衡 = +0.326（可忽略）
```

**n=12**　等级 **B**（两次独立运行一致：`t=+4.86` 与 `t=+5.45`）

**排除的替代解释**：不是能量差异（能量严格匹配）。

### 4. 边界（decay + moment reset）保护旧任务

```
同协议 retention：
  nosleep vs direct :  t = +10.26（不睡显著更差）

T10 十任务（n=8）：
  最早任务 end ppl   direct 38.27 < nocons 39.03 < nosleep 39.51
  direct vs nocons   t = −3.60
  direct vs nosleep  t = −10.27
```

**等级 A**

**关键区分**：保护旧任务的是**边界本身**，不是写入——`nocons`（不写但保留边界）已显著优于 `nosleep`。

#### 抗遗忘的两层拆分（定稿表述）

整体抗遗忘效果由**两层机制叠加**构成，且两层都已被**分别消融**：

| 层 | 机制 | 独立证据 |
|---|---|---|
| 第一层：**基底** | 睡眠边界（decay + moment reset） | `nocons` vs `nosleep`：t=+10.26；T10 最早任务 39.03(nocons) < 39.51(nosleep)，t=−10.27；T10 聚合 forgetting `nosleep` 一致更差（t=−2.65…−13.6） |
| 第二层：**增量** | 坐标对齐式写回（γ·W_fast） | **前向适应**：`direct` vs `nocons` t=+5.30（gain@40，n=12）；`shufwrite ≈ nocons`（t=−0.38）→ 打乱后增量归零 |

> ⚠️ **不要把第二层的"记忆留存增量"说满**（这是本项目最容易被写成过界的地方）：
> 写入带来的留存增量**只在最早的任务上成立**（T10 最早任务 `direct` 38.27 < `nocons` 39.03，
> t=−3.60），在 **T10 聚合相对遗忘上可忽略**（`direct` −0.96%±10.9 vs `nocons` −0.88%±10.7，
> n=8；逐任务异质性主导，只有单个任务显著 −3.05%，t=−4.56——见 ICLR 稿 §Results 十任务段）。
>
> 因此第二层的准确表述是：**主要贡献前向适应增益，并附带任务级（非聚合级）的留存增量**。
> 写成"对齐写入显著提升整体抗遗忘"会与归档数据冲突。

即：**边界负责"不遗忘的底"，对齐写入负责"底之上的前向适应增益 + 任务级留存增量"**。
消融方式：`nosleep` 消融第一层，`shufwrite`/`nocons` 消融第二层。写作时不要把两层混成一句
"睡眠巩固带来抗遗忘"——那样会丢掉第一层不需要写入即可成立这一事实。

## 二、D 级：明确的阴性结论

### 6. 系统里**显式设计的"选择"机制是惰性的**

```
‖Q‖ ≈ 0.002   vs   ‖W_fast‖ ≈ 3.6      → Q 写入仅占 0.4%
qonly ≈ nocons（n=4）
```

**等级 D**

**这是论文张力的来源**：

> **显式设计的选择机制（success-gated Q）不起作用；**
> **起作用的是一个没有选择目标的标量写回。**

## 五、一句话版本

> **一个标量均匀、无选择目标的 fast→slow 写回，其效果完全取决于写落在哪些坐标上。**
> 保持总能量与规则不变、只打乱坐标分配，效应即被完全消除（`final_ppl` t=+5.94, n=12），
> 且在 3 倍写入强度范围内，错配的写始终停在"不巩固"的地板上。
> **而系统里那个显式设计的"选择"机制（Q）是惰性的。**

**这句话需要的三个前提都已被独立检验**：能量匹配、多强度、无 pre 混淆。
